2. ## ChatML
{
    "role":"system"|"user"|"assistant"
    "content": "string"
}

if the role is system then the content type must be system prompt, else if role type is user then the prompt is something entered by user and if the role is assistant then prompt is the output is the passing back for the next set of tokens.

used by ChatGpt and gemini
